## Duplicate-control rule

Before processing any future URL, compare its Amazon ASIN, URLs, title, brand, model/identifier, exact colour, and variant against `uploaded-products.json`, the HAND CREATION register, and every other prepared product record. If it appears identical or materially the same, stop before extraction or image work and ask the user to confirm whether it should be processed.
