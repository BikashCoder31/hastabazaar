# Migration reference

This directory contains the reusable, non-customer material retained from the previous site before WordPress and its backups were removed.

- `migration/catalog-content.json` — 85 products, 24 published pages/posts, 33 categories, and media metadata
- `migration/media/` — 305 original files referenced by the exported catalogue and brand records
- `migration/media-manifest.txt` — source-relative file inventory
- `brand/hathkriti-logo-master.png` — editable master brand asset

Customer, user, password, database credential, and order exports were intentionally not retained. Legacy HTML and URLs are reference material only and must be reviewed and normalized before becoming live content.
