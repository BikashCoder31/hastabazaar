## Cross-cutting acceptance coverage

- Financial tests include NPR 1,000 → NPR 90 retained → NPR 910 entitlement, half-up paisa reconciliation, maker-funded versus platform-funded discounts, proportional/full refunds, post-payout adjustments, duplicate requests, open-order configuration changes and fixed-price purchasing without an automatic 9% deduction.
- Transaction snapshots preserve route, model, seller, issuer, beneficiary, agreement, calculation inputs and setting versions. Later configuration/profile changes do not rewrite old orders, invoices, balances or agreements.
- Local staging refuses production origins and remote database/SMTP/R2 bindings; fixtures use only `@local.hastabazaar.test`, simulated payments and conspicuous simulation labels.
- Saved addresses, ordering for another person, checkout prefill, customer counts, optional product materials/stories, stable seller identity and actual barcode/QR rendering remain visible above as Milestone 3 development—not misclassified as external production dependencies.
