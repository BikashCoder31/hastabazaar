- A verified identity/PAN file and its protected fields are locked. Unrelated contact edits remain possible. Draft restoration cannot overwrite read-only fields or attach files to disabled controls.
- The owner requests an exact document replacement with a retained reason. A current independent Super Admin grants/rejects a version-bound permission. A new eligible reviewer can revalidate an unused permission after authority changes; stale permission/decision versions fail.
- Replacement consumes one permission atomically, retains the old verified file and adds pending evidence. Correction grants a new exact permission on the same request and original one-service-day clock. Unverified evidence has a separate owner-only correction path and cannot bypass a verification race.
- Verification updates current evidence pointers while preserving the original agreement acceptance and document/audit history. Verification does not activate a seller, publish a product or enable a payout.
- Decision commands replay exactly after uncertain responses without duplicate audit/task/notifications. Current-source predicates suppress superseded document and request messages; staff and owner links open the exact case/version.
- Seller registration shows locks, private evidence, request/review reasons and correction controls. Focused Super Admin pages use the common review workspace with current facts, evidence versions, first-triage deadline, history and conflict restrictions. Files are opened through private authenticated endpoints. Bank evidence stays Super Admin-only even for originally registered sellers.
