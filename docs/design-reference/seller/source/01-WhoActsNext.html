Six rules both sides follow

1Every item says whose turn it is: Your turn (dark) or With Hastabazaar (blue). A status never appears without an owner.
2The same reference on both sides: HB-24811, PO-0143, the product name. Search finds it in Seller Studio and in Super Admin.
3One seller action creates one task in Super Admin Today, starting with a verb and naming the seller and the reference.
4Every Super Admin decision changes the seller’s screen and sends a notification at the same moment.
5Deadlines use the same clock on both sides. Late shows red on both.
6Sellers never see staff names or private notes. Super Admin sees the seller’s reply word for word.
