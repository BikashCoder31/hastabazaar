How returns work

Customers can ask to return within 7 days of delivery. The seller can add their side, but can't block a return on their own.

For handmade items, small differences in colour or finish are normal. Answer the four questions to decide whether this is normal variation or different from the listing.

If the item is faulty or different from the listing, the customer pays nothing to send it back. We check it within 3 working days of receiving it.
